# Variable Naming Convention in Go

| Name | Meaning | Typical usage             |
| ---- | ------- | ------------------------- |
| `T`    | Type    | General-purpose functions |
| `K`    | Key     | Maps and dictionaries     |
| `V`    | Value   | Maps and dictionaries     |
| `E`    | Element | Collections               |
| `R`    | Result  | Transformations           |
